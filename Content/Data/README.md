# Astronomical Tables

The CSV files in this directory are exports of the maintained Unreal data
tables. They retain the current PHAROS constellation connections and edits.
Names, star identifiers, and positions are factual astronomical data.

For the Western constellation-line definitions and their first-party edits,
retain [the upstream MIT notice](../../Docs/Legal/Licenses/Stellarium_Western_Lines_MIT.txt)
and the PHAROS [MIT License](../../LICENSE). This does not assign an MIT
