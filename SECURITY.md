# Security

PHAROS executes user-defined C++ controllers as native code with the
application's permissions. Controllers are not sandboxed; compile and run
only code you trust.

Report vulnerabilities through GitHub's private reporting channel when
available. Otherwise, request a private contact without publishing sensitive
details. Keep credentials, confidential scenarios, personal information,
and exploit details out of public issues.

Use the [issue tracker](https://github.com/BrenoRaiher/PHAROS/issues) for ordinary
defects and the [support guide](Docs/Release/SUPPORT.md) for useful diagnostic
information.
