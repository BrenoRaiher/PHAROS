# Changelog

## 1.0

- Coupled hierarchical articulated rigid-body and orbital propagation.
- Variable-mass dynamics with geometric-center-of-mass translation, component
  mass-rate and mass-second-derivative terms, and nozzle carrier-velocity terms.
- Configurable gravity, atmosphere, aerodynamics, solar radiation pressure,
  actuators, and user-authored controllers.
- Analytic derivatives for prescribed thrust and specific-impulse profiles,
  with optional commanded-thruster discharge derivatives in the Controller API.
- Standalone scenario execution, Controller SDK, template, and reference dialog.
- TGSCN import and export, saved scenarios, run continuation, telemetry,
  plots, and interactive visualization.
- Legal acceptance records, third-party notices, and scenario-library recovery
  backups.
