# PHAROS 1.0

Platform for Hierarchical Articulated Rigid-body and Orbital Simulation.

Run `PHAROS.exe` from the package root. Keep the accompanying directories
beside it; they contain the engine, scientific data, controller compiler,
and other runtime resources. No Unreal Editor or Visual Studio installation
is required. Install the supplied Unreal prerequisites if Windows reports a
missing runtime dependency.

Scenarios, controllers, results, and preferences are stored in the current
user's local application-data directory, separately from this package.
See [Privacy](PRIVACY.md) and [Support](SUPPORT.md) for details.

PHAROS is for research and educational use. It is not certified for
operational or safety-critical decisions. Compile and load native C++
controllers only from trusted sources.
