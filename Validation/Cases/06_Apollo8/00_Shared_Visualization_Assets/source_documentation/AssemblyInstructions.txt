APOLLO 8 COMMAND AND SERVICE MODULE
ASSEMBLY INSTRUCTIONS
=====================================

PACKAGE PURPOSE
---------------
This package is a simulator-oriented reconstruction made from the Pinshape
"Apollo Command and Service Module" STL set by lowracer.

The original downloaded STLs were separated and placed individually for
3D printing, so their original assembly transforms were not preserved.

This package:
  * rescales the exterior Apollo 8 parts to FULL-SIZE CENTIMETERS;
  * removes the print-bed translations;
  * rotates parts into a single Apollo spacecraft body-axis convention;
  * supplies four individually oriented SM RCS quad files;
  * supplies a deployed Apollo 8 high-gain antenna reconstruction.

MODEL SCALE
-----------
The source STL headers identify the source coordinates as millimeters.

Calibration used here:
    Pinshape CM heat-shield diameter = 133.49 source mm
    Apollo CM diameter               = 154 in = 391.16 cm

Therefore:
    1 source STL coordinate unit = 2.930256948 cm in this package.

ALL STLs IN THIS ZIP USE CENTIMETERS.

COMMON APOLLO BODY FRAME
------------------------
Package origin:
    Center of the Command Module aft heat-shield / CM-SM mating plane.

Axes:
    +X = forward, toward the Command Module nose
    +Y = spacecraft starboard / crew right
    +Z = crew-feet direction

This is a right-handed coordinate system.

PRIMARY AXIAL STACK
-------------------
The five main axial meshes are reconstructed directly from their scaled source
mesh extents, with all mating planes coincident:

1. SM_Engine
   attaches to the aft end of SM_Lower_End / SM_Body.

2. SM_Lower_End
   overlaps the aft portion of SM_Body. It is an aft structure, NOT an extra
   cylinder to place behind the body.

3. SM_Body
   extends from X = -458.585 cm to X = 0 cm.

4. CM_Heat_Shield
   starts at X = 0 and occupies the aft/base portion of the CM.

5. CM_Upper_Shell
   also starts at X = 0 and contains the conical Command Module exterior.

The CM heat shield and upper shell intentionally overlap because the heat shield
is part of the CM base structure.


SERVICE MODULE RCS QUADS
------------------------
Four copies are supplied as separate already-oriented files:

    SM_RCS_Quad_A.stl = quad near -Z
    SM_RCS_Quad_B.stl = quad near +Y
    SM_RCS_Quad_C.stl = quad near +Z
    SM_RCS_Quad_D.stl = quad near -Y

NASA reference geometry used:
    common RCS X station relative to CM aft heat-shield OML = -41.1 in
    distance from spacecraft X axis = 6.89 ft
    clocking offset = 7.25 deg

Component-center placement used in this package:
    A = (-104.394, -26.503, -208.328) cm
    B = (-104.394, 208.328, -26.503) cm
    C = (-104.394, 26.503, 208.328) cm
    D = (-104.394, -208.328, 26.503) cm

The Pinshape quad already models the four thrusters, so do NOT duplicate
thrusters inside each quad.


HIGH-GAIN ANTENNA
-----------------
Use:
    SM_High_Gain_Antenna_DEPLOYED.stl

Apollo 8 was the first Apollo mission to use the deployable four-dish
S-band high-gain antenna.

The deployed boom direction is constrained by the Apollo 8 Mission Report:
    90 deg to the spacecraft longitudinal X axis
    azimuth = 52.25 deg from -Y toward +Z

Direction from hinge toward dishes:
    (0.000, -0.612, 0.791)

The Pinshape download does NOT preserve the HGA hinge's original Y/Z
translation. Therefore:
    * deployed BOOM ORIENTATION is engineering-document constrained;
    * aft-bulkhead mounting is correct in topology;
    * exact hinge Y/Z in this package is a reconstruction, not a recovered
      original CAD transform.

If your simulation requires millimeter-accurate HGA hinge kinematics, treat the
HGA position as an adjustable calibration parameter.

CM/SM UMBILICAL
---------------
SM_CM_Umbilical.stl is retained because it is a useful major exterior block.

The Pinshape export does not preserve its assembly transform. In this package it
is mounted across the CM/SM interface on the +Z side as a visual reconstruction.

For pure rigid-body dynamics it may be omitted without affecting the major
spacecraft silhouette.


APOLLO 8 DOCKING PROBE
----------------------
The Pinshape ZIP contains a detailed docking-probe assembly and its subparts.
They are intentionally NOT included in this Apollo 8 exterior package.

The package is focused on the exterior major blocks needed for the Apollo 8
CSM configuration and simulator visualization.

WHY V3 WAS WRONG
----------------
The printable SM_Body mesh contains protruding exterior hardware. Because of
that, its geometric bounding-box center is NOT the center of the cylindrical
Service Module wall.

Original Pinshape SM_Body:
    bounding-box XY center = (68.460052, 70.764999) source mm
    fitted cylinder axis   = (69.118621, 73.679578) source mm

At the package full-size scale, the cylinder therefore sat:
    +1.929776 cm in Apollo +Y
    +8.540465 cm in Apollo +Z

away from the common CM/SPS spacecraft axis.

CORRECTED COMPONENTLOCAL PLACEMENT
----------------------------------
SM_Body.stl:
    Position = (-229.292606, -1.929776, -8.540465) cm
    Rotation = Identity
    Scale    = 1

ComponentLocal/SM_Body.stl itself is unchanged from V3.
Only its placement vector changed.
