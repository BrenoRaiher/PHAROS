# JWST Figures

Each figure is generated by `analysis/plot_current.py` from the recorded data and saved as PNG plus editable SVG.

1. [Trajectory](01_trajectory.png): PHAROS and NAIF paths with an Earth-centered moving origin and ICRF axes; this is not a rotating L2 frame. Open circle marks the initial point, square the final point.
2. [State Differences](02_state_residuals.png): sampled barycentric position/velocity norm and component differences, with maneuver and modeled SRP-transition epochs. The sharp reference feature near 10 January is discussed separately.
3. [Finite Burns](03_burns.png): commanded-thrust histories and direction tracking for all three maneuvers. The plotted magnitudes are calibrated commands, not claims of exact flight impulses.
4. [Reference Transition](04_reference_transition.png): a one-second reference-velocity query and raw type-13 nodes around 10 January. This figure concerns the retained reference, not PHAROS instability; see `../REFERENCE_QUALITY.md`.

5. [Before/After Retuning](05_retuning_comparison.png): position and velocity differences for the earlier 307.873 km case and the retained joint refinement, with identical physical assumptions and output epochs.

The optional presentation TGSCNs are not the numerical source of these figures.
